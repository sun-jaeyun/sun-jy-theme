# Sunwjy Theme

A dark color theme for Visual Studio Code — a fork of the **Community Material Theme (Legacy)**, *Darker High Contrast* variant.

## Why?

I love the Community Material Theme (also known as the legacy version of Material Theme), especially the Darker High Contrast variant. However, starting December 2023, the official legacy version is no longer available on the marketplace, and the Darker High Contrast from the new official Material Theme doesn't match my preferences.

So I forked the legacy version to keep using the theme I love — and to keep it alive.

## Installation

**From the Marketplace**

1. Open the **Extensions** view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Search for **Sunwjy Theme**.
3. Click **Install**.

**Activating the theme**

1. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
2. Run **Preferences: Color Theme**.
3. Select **Sunwjy Theme**.
